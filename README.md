# GoldMind AI Flutter

Professional dark-theme Flutter prototype for XAUUSD paper analysis.

## Included
- Dark trading dashboard
- XAUUSD price card
- H4/H1/M15 trend cards
- Technical analysis screen
- Entry / SL / TP / R:R paper setup
- AI insights screen
- Trade history
- Settings screen
- No broker execution

## Build an APK

Install Flutter and Android SDK, then:

```bash
flutter pub get
flutter build apk --release
```

The APK is normally produced under:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## Important
This app uses demo/sample market values. It is a UI prototype and does not provide live market data or broker execution.
